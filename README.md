# sports-shop

Next.js sports accessory storefront with Navy, White, and Orange branding and prices in AED.

## Pages
- `/` — Home (hero showcase, categories, featured products, UAE shipping banner)
- `/products` — All 8 products in AED with category filter, search, sort, and quick-view specs
- `/cart` — Shopping cart with quantity controls, free UAE delivery meter (AED 250), and 5% VAT calculation
- `/checkout` — UAE delivery form, payment options (Card, Apple Pay, Cash on Delivery), and order confirmation

## Run locally
```bash
npm install
npm run dev
```
